- AI Health Check with Posture Recognition

A full-stack AI-powered health monitoring web application that predicts potential health risks such as obesity, cardiac issues, and hypertension using lifestyle data and posture analysis.

- Live Demo:
https://ai-health-check-with-posture-recogn.vercel.app

- Backend API:
https://ai-health-check-with-posture-recognition.onrender.com

- Project Overview

This project allows users to:

Create an account and securely log in

Enter daily health and lifestyle data

Analyze posture score and health parameters

Predict health risks using a trained machine learning model

View past health prediction history

The application is deployed using free cloud services and demonstrates end-to-end full-stack development.

- Features

User authentication (Signup and Login)

- How It Works

User signs up and logs in

Health and lifestyle inputs are collected

Data is preprocessed and passed to ML model

Model predicts health risks

Results are stored and shown to the user

#Note on Free Hosting

Backend uses Render free tier

Service may sleep during inactivity

First request can take 30–50 seconds (cold start)

This is expected behavior on free hosting.
